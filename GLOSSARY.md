# Windows helpers

Personal commands for recurring Windows tasks.

## Language

**Directory shortcut**:
A named destination the user can navigate to using its key.

**Output option**:
A named copy recipe identifying a destination and the files to place there.

**Staging output**:
A directory containing game executable, multiplayer client, and resources prepared for distribution.

**Installed game**:
The local game installation into which resources can be copied.
